# Food Delivery Time Optimization & Demand Analysis

## Overview
Analyzed food delivery data to identify factors affecting delivery time.

## Tech Stack
- Python (Pandas, Matplotlib)
- SQL
- Excel

## Key Insights
- Peak hours increase delivery time by 30–40%
- Distance impacts delivery duration

## Outputs
Check outputs/ folder for graphs

## How to Run

pip install -r requirements.txt  
python src/preprocessing.py
